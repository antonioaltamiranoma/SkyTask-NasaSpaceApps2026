Add Sky Task to your site

Like a CAPTCHA box: one script tag, one element. The widget brings its own look; no CSS needed.

  1. Load the widget once per page: 
    <script src="https://sky-task-c4048.web.app/widget/sky-task.js" defer></script>
  2. Put the element where the task should appear: 
    <sky-task api="https://skytask-api-659703561463.us-central1.run.app/v1"
          site-key="demo" count="3" result="score"></sky-task>
    site-key
    identifies your site (demo keys: demo, demo-game)
    count
    tasks per challenge, 2–10
    result
    none (science: just record) or score (games: 0–100%); token for CAPTCHA is future work
    theme
    light, dark or auto
    layout
    box (form) or screen (inside a game panel)
  3. React to the answer (optional): 
    document.querySelector("sky-task").addEventListener("sky-task-result", (e) => {
  console.log(e.detail);   // {"recorded": true}  or  {"score": 75}
});
