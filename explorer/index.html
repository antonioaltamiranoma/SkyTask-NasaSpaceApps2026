Add Sky Task to your site

Like a CAPTCHA box: one script tag, one element. The widget brings its own look (no CSS needed), and every answer helps analyze NASA SPHEREx data.

  1. Load the widget once per page, anywhere (usually in <head>): 
    <script src="https://sky-task-c4048.web.app/widget/sky-task.js" defer></script>
  2. Put the element where the task should appear: 
    <sky-task api="https://skytask-api-659703561463.us-central1.run.app/v1"
          site-key="demo" count="3" result="score"></sky-task>
    Attributes
    AttributeRequiredDefaultWhat it is for
    apiYes, on your sitethis page’s own /v1 Address of the Sky Task API. On any site other than this one, set it to https://skytask-api-659703561463.us-central1.run.app/v1, otherwise the widget looks for the API on your own server.
    site-keyYesnone Says which site is asking. The server uses it to decide what that site may request (how many tasks at most, which result modes) and to tell sites apart in the data. Public keys you can use now: demo and demo-game (up to 10 tasks, none or score). It is not a secret; it is visible in your page.
    countNo2 How many tasks one challenge has, 2 to 10. More tasks = more science per visit but a longer wait for the person. 2–3 suits a form; 3–5 suits a game break. The server may lower it to the site key’s maximum.
    resultNonone What your page gets back when the person finishes.
    none: nothing to grade, answers are just recorded (pure citizen science).
    score: a percentage 0, 25, 50, 75 or 100 you can turn into a reward in a game; it never says which answer was right.
    token: a pass token for CAPTCHA-style checks; not available yet (the API answers 501).
    themeNoauto Colours: light, dark, or auto to follow the visitor’s system setting. Fine-tune colours with CSS variables such as --sky-task-accent (see the widget README).
    layoutNobox Shape. box: a card up to 380 px wide, for forms and sidebars. screen: fills whatever space you give it and uses two columns from 440 px wide, for game panels and bottom sheets.

    Changing api, site-key, count or result on the element starts a fresh challenge. The disclosure line “Helps analyze NASA SPHEREx data” always shows and can’t be hidden.

  3. React to the answer (optional): 
    const box = document.querySelector("sky-task");
box.addEventListener("sky-task-result", (e) => {
  // result="none":  e.detail = { mode: "none",  recorded: true }
  // result="score": e.detail = { mode: "score", score: 75 }
  if (e.detail.mode === "score") giveReward(e.detail.score);
});
box.addEventListener("sky-task-error", (e) => {
  // e.detail = { stage, status, message }
  console.warn("Sky Task:", e.detail);
});
    Events (both bubble out of the element)
    EventWhendetail fields
    sky-task-resultThe person answered every task and the API accepted them. mode: the result you asked for.
    recorded (mode none): true when the answers were stored.
    score (mode score): 0–100 in steps of 25; known tasks count by correctness, open science tasks count as a coin flip because nobody knows the answer yet.
    sky-task-errorSomething failed; the widget shows a “Try again” button itself. stage: where it failed: session, challenge, image or submit.
    status: the HTTP status, if any. 403 = site key unknown or mode not allowed for it; 410 = challenge expired (10 minutes); 503 = this visitor has seen every task we have right now; 501 = token mode not available yet.
    message: a readable explanation for your logs.

    Methods: box.reset() starts a new challenge. Full reference: the widget README and the API contract.
